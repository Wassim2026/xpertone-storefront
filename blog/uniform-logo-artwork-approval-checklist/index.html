Uniform Logo Artwork: A Proof-Approval Checklist for UAE Companies

A production-proof checklist for Arabic and English logos, file versions, garment colours, dimensions and repeat-order records.

Published 12 October 2026Dubai, UAEApprox. 7 min read

Your uniform supplier has the company logo, but does everyone know which version should be used? A bilingual name, a separate project logo, a department label and a back print can create several different production instructions within one order.

For UAE companies ordering branded workwear, the safest purchasing workflow is to approve a complete artwork specification tied to a particular garment. “Use our usual logo” leaves too much room for interpretation.

This checklist explains what to send, what to inspect and how to record approval. If you are still choosing the application method, start with our embroidery-versus-DTF guide.

Create one clear artwork package

Give the supplier one folder or clearly labelled set of files containing:

  • The current master logo
  • A reference image showing how it should look
  • Approved Arabic and English wording, where required
  • Brand colour references, if your company has them
  • Garment references and colours
  • Requested positions and dimensions
  • A list of variations, such as department names

Mark superseded artwork clearly. A filename such as “logo-final-new-2” does not reliably identify what has been approved. A version number and date are easier to track.

If the logo belongs to a client, contractor or partner, confirm you have permission to apply it to the garments before requesting production.

Ask which file format the production team needs

Send the original design file if you have it and ask which export format the supplier prefers. Do not assume that every PDF contains editable vector artwork or that changing a file extension improves its quality.

A screenshot may be useful as a visual reference, but ask the production team to inspect the underlying artwork at the intended output size. If the only available file is small or unclear, find out whether rebuilding it is necessary and whether that introduces a separate charge or approval step.

For text-based artwork, a designer can prepare an outlined production copy when appropriate. Outlining turns text into vector shapes and helps avoid missing-font problems; the original editable version should be retained because outlined text can no longer be edited with ordinary text controls. Adobe explains text outlines and their editing limitations.

There is no need to prescribe a universal resolution or file recipe before the production method is known. Ask the supplier to confirm that the supplied artwork is usable for the exact garment, dimensions and process.

Review Arabic and English as separate approval items

Have a person who can read each language check the actual production proof. A correct company name in an email does not prove that it is correct in the artwork.

For bilingual branding, review:

  1. The spelling of each company or department name
  2. Arabic letter forms and joining as displayed in the exported proof
  3. Word order and alignment
  4. Punctuation, numerals and telephone-number order, if used
  5. The visual balance between Arabic and English
  6. Whether small text is readable at the proposed physical size

Avoid asking a production operator to guess an official Arabic company name from an English transliteration. Supply approved wording. If you change the spelling after a proof has been prepared, require a new proof carrying the corrected version.

Review the exported file itself, not only the editable artwork on the designer's computer. The exported proof is what the wider team can check and sign off.

Define placement from the wearer's perspective

“Left chest” should mean the wearer's left. State that in the artwork sheet and show the location on a front view of the actual garment style.

For each application, record:

  • Artwork version
  • Garment reference and colour
  • Front, back or sleeve position
  • Logo width and height in millimetres
  • The agreed placement reference, such as a seam or pocket edge
  • Colour version and application method

Do not copy the dimensions from a large back print onto a chest logo. Treat each position as its own production item.

Ask how placement will be handled across the size range. A layout that looks balanced on one sample may need review on the smallest garment or on a style with different pocket positions.

Approve colour on the relevant background

A white logo on navy fabric and the same logo on beige fabric are different visual combinations. Identify the correct artwork version for every garment colour.

Where colour matching matters, provide the company's recognised reference and ask what matching is achievable with the selected process. Check the proposed result on a physical sample when needed. A phone screen should not be the only reference for a colour-critical order.

If the design has a solid background box, confirm that it is intentional. If it should appear without a surrounding box, make that requirement explicit and inspect the proof carefully.

Avoid adding a new slogan, phone number or website address casually at the last stage. Every additional detail needs a readability and accuracy check.

Separate layout approval from sample approval

A digital proof can show the intended spelling, position, relative appearance and dimensions. It does not demonstrate the feel or finished result on the garment.

For orders where the branding result needs physical approval, agree a sample process before the main run. Confirm whether the sample uses the actual garment and application method. Ask about any sample charges and how approval affects the production schedule.

Review pocket access, seams and the normal use of the garment as well as the appearance of the logo. For protective clothing, ask the supplier and responsible safety person to confirm whether the proposed customisation is permitted for that exact product. Branding approval should not override its protective specification.

Browse the uniform catalogue to identify the garment, or the safety-vest range if your order includes site identification wear.

Use a written approval record

A useful approval is specific enough to retrieve months later. Include the proof reference, revision, date, garment reference, colour, logo dimensions, positions and approved variations.

For example, an internal approval record might read:

“Approved artwork revision 03 for the navy shirt reference listed on purchase order 104. Front and back positions and dimensions are as shown in proof 03. Department wording follows the attached approved list. Any change requires a revised proof.”

This is an example of a record, not a production instruction for a live order.

Ask one authorised person to consolidate feedback. Conflicting comments from procurement, marketing and a site supervisor are easier to resolve before production than after garments have been branded.

Keep a repeat-order pack

Save the approved artwork and proof together with the garment reference and final order specification. If there is an approved physical sample, label it with the same revision.

On a reorder, confirm that the garment, branding process and artwork are unchanged. A new colour, different garment or revised logo should trigger the relevant checks again.

Frequently asked questions

Is a WhatsApp image enough to print our logo?

It can help explain the intended appearance. Ask the production team to assess the actual file for the required output size and process, and supply the original artwork when available.

Should Arabic wording be typed again by the supplier?

Provide approved wording and a visual reference. Have an Arabic reader check the final exported proof, including any wording that was retyped or converted.

Can we approve the logo without choosing the uniform?

You can approve the master brand artwork, but production approval should also identify the garment, its colour, the application method, dimensions and position.
